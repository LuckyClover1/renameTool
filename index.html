关于本工具

这是一款本地批量文件重命名网页工具。你选择的文件始终保留在自有设备上， 不会上传到任何服务器。通过浏览器 File System Access API 直接修改文件夹内的文件名， 适合需要批量改名、批量加前缀后缀或按序号重命名的场景， 例如相机照片、下载素材、项目文档等。

主要功能

  • 添加前缀：为文件夹内所有文件统一加上名称前缀。
  • 添加后缀：在扩展名前插入后缀，便于区分版本或批次。
  • 替换字符串：批量查找并替换文件名中的指定文字。
  • 序号模板：按 file_{num:03d}{ext} 等模板生成连续编号文件名。
  • 扩展名过滤：仅处理 .jpg、.png、.pdf 等指定类型，避免误改其他文件。
  • 实时预览：选择文件夹后自动列出原文件名与新文件名对照，确认后再执行。

使用步骤

  1. 使用 Chrome 或 Edge 86 及以上版本打开本页面。
  2. 点击「选择文件夹并授权」，授予该文件夹的读写权限。
  3. 选择重命名模式并填写参数，在预览表中核对新文件名。
  4. 确认无误后点击「执行重命名」；操作不可撤销，建议先备份重要文件。

常见问题

文件会上传到网站吗？
不会。所有读写均在本地浏览器内完成，本工具不收集、不传输你的文件内容。
支持哪些浏览器？
推荐使用 Chrome、Microsoft Edge 86+ 等支持 File System Access API 的 Chromium 内核浏览器。
可以重命名子文件夹里的文件吗？
当前版本仅处理所选文件夹根目录下的文件，不包含子目录中的文件。
重命名失败常见原因？
目标文件名已存在、新名称含非法字符，或文件被其他程序占用。请根据状态栏提示排查。
与安装版重命名软件有何区别？
无需安装，打开网页即可使用；但需浏览器授权，且依赖现代浏览器 API，功能聚焦于单文件夹批量改名。
